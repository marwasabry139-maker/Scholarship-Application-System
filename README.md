# Scholarship Application & Approval System

## Project Overview
This repository contains the System Analysis & Design documentation for the Scholarship Application & Approval System project.

---

## 1. System Request

* Project Name: Scholarship Application & Approval System
* Project Sponsor: University Scholarship Office / Academic Affairs

* Business Need:
  1. Replace slow and inefficient paper/email-based application procedures with an automated workflow.
  2. Eliminate student document loss and application tracking errors.
  3. Create a centralized database to easily audit, review, and evaluate candidate files.

* Business Requirements:
  1. Provide an online registration and application portal for students.
  2. Implement a scoring and document review module for committee members.
  3. Send real-time email notifications regarding application status updates.
  4. Allow applicants to track their submission progress live.

* Business Value:
  1. Saving administrative time and review effort.
  2. Increasing evaluation transparency and data accuracy.
  3. Reducing overall paper consumption and operational costs.

* Special Issues or Constraints:
  1. Strict annual deadlines for scholarship cycles.
  2. High data security requirements to safeguard sensitive student records and personal documents.

---

## 2. Feasibility Analysis

### A. Technical Feasibility
* Technologies: HTML, CSS, JavaScript, and SQL / Relational Databases.
* Development Tools: Visual Studio Code, Git/GitHub, and Trello.
* Environment: Web-accessible platform compatible with modern desktop and mobile browsers.

### B. Economic Feasibility
* Costs: Minimal to zero initial software expenses using free, open-source tools and educational platforms.
* Benefits: Reduces university administrative overhead, saves paper expenses, and minimizes review labor hours.

### C. Organizational Feasibility
* User Acceptance: High acceptance expected from applicants (for smooth digital submissions) and committee members (for streamlined grading).
* Usability: Designed with a clean, intuitive user interface suitable for all technical skill levels.
